# Rubik's Cube Solver

This project is a Rubik's cube solver developed using C++ for the main logic and OpenGL for visualizing the solution process via 3D convolution.

## Features

- **Rubik’s Cube Solver**: Implements efficient solving algorithms for the 3x3 Rubik's cube.
- **3D Visualization**: Uses **OpenGL** to visualize cube movements and the solution process in real time.
- **Customizable**: Users can input custom scrambles or use random cube states for solving.
- **Cross-platform**: Developed using **C++** and **OpenGL**, making it compatible with multiple operating systems.
- **Step-by-step Animation**: Watch the cube's transformation as each solving step is applied, offering a clear understanding of how the algorithm works.

## Technologies

- [C++](https://isocpp.org/)
- [OpenGL](https://www.opengl.org/)
